# IP Info

A browser-based IP information interface that presents network/IP-related information in a simple web UI.

## Features
- Clean IP information dashboard
- Browser-based interface
- Responsive layout
- Client-side functionality

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Getting Started
Clone the repository and open `index.html` in a modern browser.

## Privacy
IP addresses can be sensitive network information. Avoid collecting, storing or sharing IP information without a legitimate purpose and appropriate notice.
